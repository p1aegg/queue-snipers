# Queue Snipers

A collection of **browser console queue snipers** for Minecraft tierlists (MCTiers, PvP Tiers, Central Tiers, etc.).

These scripts inject a floating UI into Discord that automatically clicks the **“Join Queue”** button the moment it appears — much faster than doing it manually.

## Available Scripts

| File              | Theme / Style                  | Features                                      |
|-------------------|--------------------------------|-----------------------------------------------|
| `22qq.js`         | Dark purple / neon             | Rainbow color slider, TURBO mode, draggable UI, settings panel, delay control |
| `Professional.js` | Clean orange / white           | Simple & polished, interval control           |
| `JP.js`           | JP variant                     | —                                             |

| `Solwce.js`       | Solwce variant                 | —                                             |
| `Zenith.js`       | Zenith variant                 | —                                             |

## How to Use

1. Open Discord in your **browser** (Chrome / Edge / Firefox recommended).
2. Go to the tier testing channel where the “Join Queue” button appears.
3. Open the browser console:
   - `F12` or `Ctrl + Shift + J` (Windows)
   - `Cmd + Option + J` (Mac)
4. Copy the entire contents of one of the `.js` files.
5. Paste it into the console and press **Enter**.
6. A floating panel will appear.
7. Adjust delay / enable TURBO if available, then click **Start** / **Join Queue**.

The script will keep clicking the “Join Queue” button until you stop it.

## Tips

- Make sure you already have access to the test/waitlist channels.
- Lower delay = faster clicks (but can look more bot-like).
- TURBO mode (when available) is the most aggressive.
- You can close the panel anytime with the ✕ button.
